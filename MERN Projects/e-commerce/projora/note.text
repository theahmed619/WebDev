use framer motion for redesign the ui and make better

This is a fantastic idea! You're right, the current dark theme is clean but static. Let's rebuild it with a modern, animated "Glass and Gradient" theme using Framer Motion.

This new design will feature:

Animated Background: A subtle, moving gradient for the entire page background.

"Glassmorphism": Your Navbar and Category bar will be semi-transparent with a "frosted glass" blur, making them float over the background.

Framer Motion Animations:

Text in your Sidebar (slider) will animate in with each slide.

Categories will stagger-animate into view.

Project cards will have a "lift" and "glow" effect when you hover over them.

Here is the step-by-step guide and the code you'll need.

Step 1: Install Framer Motion
In your user-frontend terminal, run this command:

Bash
npm install framer-motion
Step 2: Remove Theme Toggle (in main.jsx and Navbar.jsx)
You said you don't want the toggle, so let's remove it.

In src/main.jsx:

Remove the ThemeProvider.

Your file should just look like this:

JavaScript
createRoot(document.getElementById("root")).render(
  <BrowserRouter>
    <UserProvider>
      <App />
    </UserProvider>
  </BrowserRouter>
);
In src/context/UserContext.jsx:

You can delete the theme, toggleTheme, and the useEffect hook associated with it (lines 10-33).

Step 3: Set the New Animated Background (in index.css)
Replace the entire content of your src/index.css file with this. This adds the animated gradient background to your whole site.

Code snippet
/* 1. Use the correct Tailwind directives */
@tailwind base;
@tailwind components;
@tailwind utilities;

/* 2. Define the new animated background */
body {
  /* This is a dark, rich gradient */
  background-image: linear-gradient(120deg, #020617 0%, #111827 50%, #1e1b4b 100%);
  
  /* This defines the animation */
  background-size: 200% 200%;
  animation: animate-gradient 20s ease infinite;
  
  /* Default text color for the whole site */
  @apply text-gray-300;
}

/* 3. The animation keyframes */
@keyframes animate-gradient {
  0% {
    background-position: 0% 50%;
  }
  50% {
    background-position: 100% 50%;
  }
  100% {
    background-position: 0% 50%;
  }
}
